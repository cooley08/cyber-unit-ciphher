          Finding the network and broadcast by hand

          1. Find the first octet in the mask that isn't 255.
          2. Block size = 256 minus that octet.
          3. Subnets start at multiples of the block size (e.g. 0, 32, 64, 96 for a block of 32).
          4. Network: the multiple at or below the IP's octet. Later octets are 0.
          5. Broadcast: the next multiple minus 1. Later octets are 255.
          6. Usable hosts = 2host bits − 2.
